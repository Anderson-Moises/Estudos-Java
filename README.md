# Estudos de Java ☕

Repositório criado para registrar minha evolução no aprendizado de **Java**, reunindo exercícios e práticas desenvolvidos durante meus estudos.

O objetivo é consolidar os fundamentos da linguagem por meio da prática, explorando diferentes formas de resolver problemas e registrando a evolução das soluções ao longo do aprendizado.

## 📚 Conteúdos praticados

* Sintaxe e fundamentos do Java
* Entrada de dados com `Scanner`
* Variáveis e tipos de dados
* Operadores
* Estruturas condicionais
* Estruturas de repetição

  * `for`
  * `while`
* Arrays
* Strings
* Métodos
* Manipulação de caracteres
* Cálculos matemáticos
* Números primos
* Fatorial
* Palíndromos
* Média, maior e menor valor
* Prática e revisão de conceitos

## 🔎 Organização dos exercícios

Os exercícios estão organizados de acordo com os conceitos praticados durante os estudos.

Alguns problemas possuem mais de uma implementação, permitindo comparar diferentes abordagens para chegar ao mesmo resultado.

Exemplos:

* `TabuadaFor.java` e `TabuadaWhile.java` — comparação entre estruturas de repetição.
* `FatorialCrescente.java` e `FatorialDecrescente.java` — diferentes formas de percorrer os valores.
* `NumerosPrimos.java` e `NumerosPrimosRaiz.java` — comparação entre abordagens para verificar números primos.
* `PalindromoExtremidades.java`, `PalindromoInvertido.java` e `PalindromoFrase.java` — diferentes estratégias para trabalhar com palíndromos.

## ▶️ Como executar

O projeto pode ser executado a partir da classe `Main`.

Cada exercício possui um método `executar()`, permitindo selecionar no `Main` qual prática será executada.

Exemplo:

```java
import model.Revisao;

public class Main {

    public static void main(String[] args) {

        Revisao.executar();

    }
}
```
